私有 (Private) 安全默认

仅 Bucket 拥有者通过 AK/SK 签名或预签名临时链接读写，适合个人备份、重要数据与内部文件。

公共读 (Public Read) 外链直访

允许任何人通过固定直链免签名 GET/HEAD 读取，写入/删除仍严格需要 AK/SK 鉴权，适合图床与静态资源。

配置允许浏览器前端直接调用该 Bucket 资源的源域名与 HTTP 方法（JSON 数组格式）。
